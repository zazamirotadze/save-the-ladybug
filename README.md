# 🐞 გადაარჩინე ჭიამაია (Save the Ladybug)
live link (ლაივის ლინკი) - https://zazamirotadze.itch.io/save-the-ladybug

ინტერაქტიული ბრაუზერული თამაში, შექმნილი HTML5 Canvas-ით, თანამედროვე JavaScript-ითა და Web Audio API-ის ხმოვანი ძრავით.

---

## 📖 თამაშის სიუჟეტი და მიზანი
- პატარა **ჭიამაია (Coccinellidae)** მიცოცავს ოთახის კედელზე ქვევიდან ზევით.
- ჭერისა და კედლის კუთხეში თავისი წებოვანი ქსელით იმალება საშიში **სარდაფის გრძელფეხება ობობა (Cellar Spider — Pholcidae)**.
- **მოთამაშის მიზანი:** ხელი შეუშალოს ჭიამაიას ობობასა და მის ქსელთან მიახლოებაში.
- **მოგება:** როცა ჭიამაიას უსაფრთხოდ მიმართავთ მარცხენა მზიანი ფანჯრისკენ, იგი ხალისით შლის წითელ ფრთებს, სახეზე უჩნდება დიდი გახარებული ღიმილი, **გამოსცემს ნამდვილ მხიარულ ხმას „ვუჰუუ!“ (ხმოვანი სინთეზი + ფორმანტები)**, ეკრანზე ჩნდება ბუშტი „ვუჰუუ! 🎉“ და გაფრინდება თავისუფლებისკენ! გამოდის ღილაკი შემდეგ დონეზე გადასასვლელად.
- **წაგება:** თუ ჭიამაია ქსელს ან ობობას შეეხება, ობობა ელვისებურად ეშვება ძაფზე და იჭერს მას — ჭიამაია **ხმამაღლა გამოსცემს განწირულ ხმოვან ყვირილს „ააა!“ (შემზარავი ტირილითა და სლუკუნით)**, ეკრანზე ჩნდება „ააა! 😭“ და ეცემა ცრემლები.

## 🎮 მართვა და გეიმპლეი
1. **ბარიერის დასმა:** დააწკაპუნეთ კედელზე (მაუსით ან თითით მობილურზე) — გაჩნდება დამცავი მწვანე ფოთოლი, რომელიც ჭიამაიას შეაჩერებს და მიმართულებას შეაცვლევინებს.
2. **პირდაპირი შეხება:** ჭიამაიაზე პირდაპირ დაწკაპუნებით იგი შეფრთხება და უკან/გვერდით შემობრუნდება.
3. **კლავიატურა:** `←` / `→` ფოთლის დასადებად, `Space` ან `Enter` ჭიამაიას პირდაპირ შესაბრუნებლად, `Esc` მთავარ მენიუში დასაბრუნებლად.
4. **5 თანდათანობით რთული ტური:**
   - **ტური 1:** პირველი ნაბიჯები კედელზე (სტატიკური ობობა, პატარა ქსელი).
   - **ტური 2:** გაფართოებული ქსელი (უფრო დიდი ქსელი ცენტრისკენ).
   - **ტური 3:** ფხიზელი სარდაფის ობობა (მოძრავი ობობა ჭერის გასწვრივ).
   - **ტური 4:** ორი ობობის ხაფანგი (ობობები ჭერის ორივე მხარეს).
   - **ტური 2:** დიდი გაქცევა თავისუფლებისკენ (სიუჟეტის ფინალური დაძაბული გამოწვევა).
   - **ტური 3:** ვიწრო მზის სხივი — ზუსტი მიმართულება და შეზღუდული გასასვლელი.
   - **ტური 4:** სამი ჩრდილი — რამდენიმე ობობას შორის გავლა.
   - **ტური 5:** უკანასკნელი ქარიშხალი — კარადა ფანჯრის ქვეშ და ყველაზე რთული გზა.

## 📜 კინემატოგრაფიული ეპილოგი (Movie Credits Crawl)
- ხელმისაწვდომია როგორც **ყველა ტურის მოგების შემდეგ**, ასევე პირდაპირ მთავარი მენიუდან ღილაკით **„ნახე ეპილოგი“**.
- ტექსტი ამოდის ქვემოდან ზემოთ როგორც ფილმის ტიტრებში (Movie Credits Crawl), გადის ეკრანიდან და ტექსტის გასვლის შემდეგ მოთამაშე **ავტომატურად ბრუნდება მთავარ მენიუში** (ასევე შესაძლებელია გამოტოვება ღილაკით).
- თან ახლავს ემოციური Web Audio API ფორტეპიანოსა და ემბიენტის მუსიკალური კომპოზიცია.
- შეიცავს ღრმა, ბრძნულ აზრებს ცხოვრებისეულ ხაფანგებზე, უხილავ მფარველობაზე და საკუთარი ფრთების გაშლის ძალაზე.

## 🔊 ხმოვანი სისტემა (Web Audio + Web Speech API)
- **ნამდვილი ხმოვანი შეძახილი და ტირილი:**
  - მოგებისას: მხიარული შეძახილი **„ვუჰუუ!“ / „Woohoo!“** (ხმოვანი სინთეზი + [u] ვოკალური ფორმანტები და გამარჯვების ჟღერადობა).
  - წაგებისას: შეშინებული ყვირილი **„აააააა!“ / „Aaaaaaa!“** (ხმოვანი სინთეზი + [a] ფორმანტური ვიბრატო, კანკალი და ტირილის სლუკუნი).
- **ავტონომიური აუდიო:** არ საჭიროებს გარე mp3 ფაილებს; ყველა ხმა ბრაუზერში სინთეზირდება.
- მუსიკა და სხვა ხმოვანი ეფექტები ერთმანეთისგან დამოუკიდებლად ირთვება/ითიშება **პარამეტრებიდან**.
- **ავტომატური გააქტიურება:** ბრაუზერის აუდიო ავტომატურად აქტიურდება ეკრანზე პირველივე შეხებისას/დაწკაპუნებისას.
