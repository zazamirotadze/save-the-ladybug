# 🐞 გადაარჩინე ჭიამაია (Save the Ladybug)

ლაივის ლინკი (live link) : https://zazamirotadze.itch.io/save-the-ladybug

HTML5 Canvas-ზე შექმნილი ბრაუზერული puzzle-თამაში, რომელშიც პატარა ჭიამაია სარდაფის ობობის ქსელს უნდა აარიდო და უსაფრთხო მზიან ფანჯარამდე მიიყვანო.

## 🎯 მიზანი და თამაშის პრინციპი

- ჭიამაია ოთახის კედელზე ქვემოდან ზემოთ მიცოცავს.
- ჭერთან და კედლის ზედა ნაწილში სარდაფის ობობები და მათი ქსელებია.
- მოთამაშემ ჭიამაიას მიმართულება უნდა მართოს ისე, რომ ობობას, ქსელსა და დონის დაბრკოლებებს აარიდოს.
- უსაფრთხო ფანჯრის მიღწევისას ჭიამაია ფრთებს შლის, ისმის გამარჯვების შეძახილი „Woohoo!“, ჩნდება „ვუჰუუ! 🎉“/„Woohoo! 🎉“ ბუშტი და იწყება გაფრენის ანიმაცია.
- ობობასთან ან ქსელთან შეჯახებისას იწყება დაჭერის ანიმაცია, ისმის შეშინებული ხმა, ჩნდება „ააა! 😭“/„Aaa! 😭“ ბუშტი და დონე მთავრდება წაგებით.

## 🎮 მართვა

1. **კედელზე დაწკაპუნება ან შეხება** — განათავსე დამცავი მწვანე ფოთოლი-ბარიერი, რომელიც ჭიამაიას მიმართულებას შეცვლის.
2. **ჭიამაიაზე პირდაპირ დაწკაპუნება ან შეხება** — შეაშინე და შეაბრუნე იგი სხვა მიმართულებით.
3. **`Space` ან `Enter`** — თამაშის დროს ჭიამაიას პირდაპირი შეშინება/შებრუნება.
4. **`Esc`** — ღია მენიუს ან ფანჯრის დახურვა; თამაშის დროს მთავარ მენიუში დაბრუნება; ეპილოგის დროს მისი გამოტოვება.

ისრები (`←`/`→`) თამაშის მართვაში არ გამოიყენება.

## 🚀 გაშვება

### პირდაპირ ბრაუზერში

გახსენი `index.html` Chrome-ში, Edge-ში, Firefox-ში, Opera-ში ან Safari-ში. ასევე შეგიძლია გაუშვა `start.bat`.

### Node.js-ით ლოკალური სერვერი

```bash
npm start
```

შემდეგ გახსენი http://localhost:3000

პროექტს გარე npm-დამოკიდებულებები არ აქვს.

## 🛠️ ტექნოლოგიები

- Vanilla JavaScript (ES6+) — გარე ბიბლიოთეკების გარეშე.
- HTML5 Canvas 2D — თამაშის გრაფიკა, ანიმაცია, შეჯახებები და ნაწილაკების ეფექტები.
- Pointer Events — მაუსის, touch-ისა და pen-ის ერთიანი მართვა.
- Web Audio API და Web Speech API — მუსიკა, ეფექტები და ხმოვანი შეძახილები.
- Responsive scaling — თამაშის 800×700 ვირტუალური სივრცე სხვადასხვა ეკრანზე ავტომატურად მასშტაბირდება.
